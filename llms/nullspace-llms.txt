# Nullspace

Nullspace is composable machines for AI agents: on-demand Firecracker
microVM compute that agents create, scale, pause, resume, and fork. It
provides isolated environments with command execution, files, preview URLs,
templates, volumes, desktop access, code interpreter, lifecycle events,
snapshots, resume, and fork.
